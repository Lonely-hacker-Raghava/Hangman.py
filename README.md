#Task 1
Hangman Game in Python

Description

A terminal-based Hangman game developed using Python. Guess the hidden word one letter at a time.

Features

- Random word selection
- Six incorrect guesses allowed
- ASCII gallows visualization
- Tracks guessed letters
- Prevents duplicate guesses from reducing attempts
- Input validation
- Win and lose conditions

Technologies Used

- Python 3
- Random module
- Functions, loops, and conditionals
- Sets and strings

How to Run

1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run "python hangman.py".

Files

- "hangman.py" — Game source code
- "README.md" — Project documentation

#Task 2: Stock Portfolio Performance Tracker

Description

A Python program that tracks stock holdings and calculates portfolio value, profit or loss, and percentage return using manually entered prices.

Features

- Add stock symbols and share quantities
- Record purchase prices
- View portfolio holdings and total cost
- Calculate current portfolio value
- Calculate profit or loss and percentage return
- Validate user inputs

Technologies

- Python 3
- Dictionaries, functions, loops, and conditionals
- Exception handling

How to Run

Run "python stock_portfolio_tracker.py" in a Python terminal.

Note: Stock prices are entered manually. The program does not fetch live market prices.

#Task 4: Rule-Based Interactive Terminal Assistant / Chatbot

Description

A Python-based interactive chatbot that recognizes user messages using keywords and regular expressions and responds with predefined answers. It loads frequently asked questions from a JSON dataset.

Features

- Recognizes greetings and thank-you messages
- Responds to help requests
- Answers sample business-hours and product FAQ questions
- Detects multiple intents in one message
- Provides current date and time
- Handles unknown questions with fallback responses
- Supports exit commands such as "bye", "exit", and "quit"
- Handles missing or invalid FAQ data
- Runs locally in the terminal

Technologies Used

- Python 3
- Regular expressions ("re")
- JSON
- Functions and loops
- Exception handling
- "datetime" and "pathlib" modules

Project Files

- "chatbot.py" — Main chatbot program
- "faq_data.json" — Frequently asked questions and sample responses

How to Run

1. Install Python 3.

2. Keep "chatbot.py" and "faq_data.json" in the same folder.

3. Open a terminal in that folder.

4. Run:
   
   "python chatbot.py"

Example Commands

- "hello"
- "help"
- "What are your business hours?"
- "What is the delivery policy?"
- "What time is it?"
- "What is today's date?"
- "bye"

Limitations

This is a rule-based chatbot, not an AI language model. It uses predefined patterns and sample FAQ responses. It does not access live product, order, or business information.

Conclusion

This project demonstrates Python programming concepts including regular expressions, intent recognition, JSON data handling, functions, and exception handling to create an interactive terminal chatbot.
